# nmbenitez.github.io

This GitHub Pages site only forwards visitors to the
[Vicarius CVE Research Tracker](https://vicarius-cve-tracker.pages.dev/), which moved off GitHub Pages.

- `/vicarius-cve-tracker/...` (the tracker's old address) keeps its path, `?cve=` / `?q=` query and `#hash`.
- Anything else goes to the tracker's home page.

When the tracker's address changes, update `NEW_ORIGIN` in every HTML file here.
